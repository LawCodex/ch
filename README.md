# LawCodex — Switzerland (ch)

Swiss federal law as Markdown: the in-force texts of the **Systematic Collection of Federal Law**
(SR / RS / RS — *Systematische Rechtssammlung*, *Recueil systématique*, *Raccolta sistematica*),
generated from the official Akoma Ntoso XML published by the Federal Chancellery on
[Fedlex](https://www.fedlex.admin.ch/).

Work in progress — corpus being generated; counts will follow.
